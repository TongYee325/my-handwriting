# 个人笔迹与偏好

## 样本

- **首要参考：** `../assets/approved-cursive.png` 是用户认可的快速行草效果，决定默认的字形、连笔程度、运笔与纸面观感。
- **辅助参考：** `../assets/reference-01.png`、`../assets/reference-02.png` 是本人原始手写扫描，用于补充个人数字、字母及数学书写特点。

样本只提供字形、运笔、间距、数学书写与纸张风格。每次作答的课程、正文、题号、姓名和学号均来自当次任务，不照抄样本内容。

## 字迹

- 白色无横线A4纸，细黑色中性笔，正面平扫观感。
- 默认是**快速行草**：中文偏细长、连笔明确、略向右斜，运笔流畅随手；字母和数字保留个人笔形，斜度、大小与落笔压力自然变化。
- 行距、缩进和基线略有变化，公式与矩阵边括号是手画的。保持辨读所需的行列关系。
- 追求平时快速写作业的观感。既不排成整齐的字帖，也不把每一行都人为扭曲。
- 计算作业可像样本一样松散双栏。其他科目依据段落、图表和公式宽度调整，不把双栏当作固定模板。

## 句末标点

默认正文句末和公式末不写中文句号 `。` 或作为句末标点的英文句点 `.`，以换行、留白或合适的逗号、分号组织内容。不要照抄风格参考中的句号。

保留小数点（如 `0.52802`）、题号和数学所需的点号，包括乘点、点积、点导数与省略号。不得为去句号改变数值或数学含义；当次任务明确要求保留的标点按其要求处理。

## 划改模式

### `none`：默认

只写最终正确内容，不主动添加错误尝试或取消标记。自然的笔压变化、轻微连笔可以保留。

用户要求清理已有划改时，同时去掉被取消的错误内容与取消笔画，留下正确补写内容；必要时整理多余等号或把补写内容移回相应位置。保留数学上有意义的负号、分数线、上横线、`≠`、`×` 等符号。

### `light`：用户要求自然划改时

划改模拟**写快造成的落笔笔误**，例如一个汉字/字母写串、矩阵名A误写成B、下标漏写、局部运算符写错。已核验的推导和数值仍是成品依据。

1. **最小局部订正。** 只处理出错的字、字母、下标或符号；正确部分保留。
2. **笔画形式。** 用一道短斜线，或两三道大致同向、近似平行的短斜线；不画交叉的X，不用大叉、涂黑块或教师式红笔批注。
3. **补写位置。** 正确字符补在原处附近或上方，字形和笔色与正文一致。
4. **按书写动作选择。** 不捏造计算结果、概念结论或整行推导错误来营造真实感，不增加原式本来不需要的显式正号。
5. **数量自然。** 多数文字照常写完，允许一整页没有划改；不设每页固定配额，不重复同一种改法形成规律。

### 局部订正示例

| 落笔笔误 | 自然处理 |
|---|---|
| 本应写矩阵名A，却落笔写了B | 在B上划一道短斜线，在附近补A；矩阵元素保持正确。 |
| 某个本来需要的运算符写成了另一符号 | 仅对该运算符做局部短斜划，在上方/旁边补正确符号；数字和变量不动。 |
| 本应写负号，却落笔写成加号 | 只对误写的加号划一道短斜线，在上方或旁边补负号；不把相邻数字一起取消。 |
| 漏写一个下标 | 在对应右下位置补上正确下标，通常无需取消整个变量。 |
| 一个汉字落笔写串 | 只划掉该字，再紧邻补写正确字。 |

最终图上，读者应能轻易区分被取消的局部笔误与有效的正确作答。若修改会造成符号歧义或挤占公式空间，这个位置就正常写，不强行添加划改。

## 当前用户指令优先

“去掉划改”“不要划改”选择`none`；“少许自然划改”选择`light`。用户对字迹松紧、纸张、版式、颜色、署名、标点和修改数量的本次要求优先于此档案。
